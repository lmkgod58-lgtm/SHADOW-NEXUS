# SHADOW NEXUS
A modular personal AI + cybersecurity + developer command center.

## Stack
- Frontend: plain HTML/CSS/JS, deployable on GitHub Pages
- Backends: small Flask services, deployable on Render
- API: JSON GET/POST

## Modules
Cyber Lab, AI Core, Web Intel, Experiment Lab, Dev Core, System Monitor.

## Security
Keep API keys and secrets on backend services. Restrict CORS to your GitHub Pages origin before production. Cyber features should target only systems you own or are authorized to test.
